# Contributing to Restaurant Intelligence

Contributions should improve the reliability, transparency, or usefulness of the project.

## Principles

- Prefer verifiable sources over unsupported assertions.
- Separate observed data from interpretation.
- Document assumptions, collection dates, and known gaps.
- Avoid committing personal, private, or restricted data.
- Keep changes focused and reproducible.

## Good contributions

Examples include:

- correcting a source or data point;
- improving collection or normalization logic;
- adding tests or validation;
- improving documentation;
- proposing a clearly scoped analytical feature.

## Pull requests

Please explain:

1. what changed;
2. why it improves the project;
3. how it was validated;
4. what limitations remain.

Use concise commit messages such as `docs: clarify source methodology`, `feat: add competitor dataset`, or `fix: normalize menu prices`.
