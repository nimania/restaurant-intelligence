# Security Policy

## Reporting a security or data issue

Do not publish credentials, private data, access tokens, or exploitable security details in a public issue.

If a vulnerability or sensitive-data exposure is discovered, contact the repository owner privately and include the affected component, reproduction steps, potential impact, and any suggested mitigation.

## Data handling

This project should not store private customer information, authentication secrets, or restricted datasets in the public repository. Public analytical datasets should document provenance and collection context where practical.
